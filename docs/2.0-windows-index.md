# Getting Started with the Web of Science PostgreSQL Database - Windows

This tutorial will help you get up and running querying the [Web of Science PostgreSQL database](https://mdlutoronto.github.io/wos-postgresql-database-getting-started/). It will cover accessing the high performance computing environment, querying the database via SQL statements and from within a python script, and downloading the results of the query.

You will need a Compute Canada account with the proper credentials to access this database. If you haven’t done so already, you should first follow the [instructions to get your account set up](https://mdlutoronto.github.io/postgresql-databases-access/).

Note: This tutorial is intended for Windows users. If you are using a Mac, check out this [tutorial](https://mdlutoronto.github.io/wos-postgresql-database-getting-started/1.0-mac-index/) instead.

**Technique:** [Searching for maps and data](https://mdlutoronto.github.io/tutorials-search/?technique=Searching+for+maps+and+data), [Text and Data Mining](https://mdlutoronto.github.io/tutorials-search/?technique=Text+and+Data+Mining) \| **Tools:** [Web of Science](https://mdlutoronto.github.io/tutorials-search/?tool=Web+of+Science)
